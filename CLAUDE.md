# Design Context

Before any UI/UX work on this project, read both files at the project root:

- [`PRODUCT.md`](./PRODUCT.md) — strategic context: register (brand), users, outcome, brand personality, anti-references, design principles.
- [`DESIGN.md`](./DESIGN.md) — visual system: North Star ("The Night Edition"), palette, typography, elevation, components, do's and don'ts. Currently a seed; re-run `/impeccable document` after redesign to capture real tokens.

Quick anchors:

- Register: **brand** (portfolio = design IS the product).
- Lane to escape: **generic dev portfolio** (cool grey + neon accent, terminal-cursor hero, decorative globe, identical project-card grids).
- North Star: **The Night Edition**. Warm-tinted near-black surface, soft cream type, single Inkwell Oxblood accent at ≤10% coverage. Serif display + humanist sans body. State-only motion.

For any deeper visual decision, defer to PRODUCT.md and DESIGN.md, not this file.
